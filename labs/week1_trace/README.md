同时需要为计算与收据增加 `discount_cents=0` 参数：金额均为整数分，
折扣从总金额扣除，结果最低为零，负折扣抛出 `ValueError`。
收据格式保持 `Total: <金额> cents`。

只允许 Claude 修改本目录的 `pricing.py` 和 `receipt.py`。
测试、练习说明及 `__init__.py` 保持不变。
